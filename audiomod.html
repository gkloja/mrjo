FABI Voice Swap

Substitua automaticamente o último áudio do WhatsApp Voice Notes usando Termux + Android.

📥 PASSO 1

Instale o Termux

O Termux é o terminal que fará a mágica acontecer. Baixe a versão oficial e atualizada pelo F-Droid.

Baixar Termux APK
🔑 PASSO 2

Permitir Acesso aos Arquivos

Para que o script consiga encontrar a pasta do WhatsApp, o Termux precisa de permissão. Cole o comando abaixo e dê "Enter":

$ termux-setup-storage

⚠️ Atenção: Um pop-up aparecerá na tela do celular. Clique em "Permitir".

🚀 PASSO 3

Executar o Script

Agora é só colar o código abaixo. Ele fará todo o trabalho de localizar, apagar o original e injetar seu áudio instantaneamente.

fabi-swap.sh
#!/data/data/com.termux/files/usr/bin/bash

clear
BASE="/storage/emulated/0/Android/media/com.whatsapp/WhatsApp/Media/WhatsApp Voice Notes"

echo -e "\e[32m╔══════════════════════════════╗\e[0m"
echo -e "\e[32m║      🎙️ FABI VOICE SWAP      ║\e[0m"
echo -e "\e[32m╚══════════════════════════════╝\e[0m\n"

echo "🔎 Procurando último áudio..."

PASTA=$(ls "$BASE" | sort | tail -n 1)
ARQUIVO=$(ls "$BASE/$PASTA"/*.opus | sort | tail -n 1)
NOME=$(basename "$ARQUIVO")

echo -e "\n📂 Pasta encontrada:\n   \e[36m$PASTA\e[0m"
echo -e "\n🎧 Último voice detectado:\n   \e[36m$NOME\e[0m"

echo -e "\n♻️ Substituindo áudio..."
rm "$ARQUIVO"
cp "/storage/emulated/0/Download/fabi.bot" "$ARQUIVO"

echo -e "\n✅ \e[32mÁudio substituído com sucesso!\e[0m\n"
echo -e "📌 Arquivo final:\n   $NOME\n"
echo "🚀 Processo concluído."
🍎 INCOMPATÍVEL

Atenção Usuários de iPhone

O iOS possui um sistema fechado (Sandbox) que bloqueia totalmente o acesso a pastas de outros aplicativos. Por isso:

  • Não funciona com iOS normal
  • Não existe Termux para iPhone
  • Impossível acessar a pasta Voice Notes sem Jailbreak
