🎙️ FABI Voice Swap

Substitua automaticamente o último áudio do WhatsApp Voice Notes
pelo áudio mais recente da sua pasta Download

⚠️ ATENÇÃO - EXTREMAMENTE IMPORTANTE

📱 Qual versão do WhatsApp você usa?

O caminho da pasta muda completamente dependendo da sua versão!

💚 WhatsApp Normal
com.whatsapp
🟢 WhatsApp Business
com.whatsapp.w4b
🔑 Para WhatsApp NORMAL:
O código do aplicativo é com.whatsapp
📥 PASSO 1

Instale o Termux

O Termux é o terminal que fará a mágica acontecer. Baixe a versão oficial e atualizada pelo F-Droid.

Baixar Termux APK
🔑 PASSO 2

Permitir Acesso aos Arquivos

Para que o script consiga encontrar as pastas do WhatsApp e Download, o Termux precisa de permissão. Cole o comando abaixo e dê "Enter":

$ termux-setup-storage

⚠️ Atenção: Um pop-up aparecerá na tela do celular. Clique em "Permitir".

🚀 PASSO 3

Executar o Script

Copie e cole o script abaixo no Termux. Ele vai:

📱 Pegar o último voice do WhatsApp
📥 Pegar o áudio mais recente do Download
🔄 Substituir automaticamente
🎵 Suporta OPUS, OGG, MP3, M4A
⚠️ Tratamento de erros
📍 Versão selecionada: WhatsApp Normal (com.whatsapp)
fabi-swap.sh
#!/data/data/com.termux/files/usr/bin/bash

set +H
clear

BASE="/storage/emulated/0/Android/media/com.whatsapp/WhatsApp/Media/WhatsApp Voice Notes"
DOWNLOAD="/storage/emulated/0/Download"

echo "🎙️ FABI VOICE SWAP"
echo ""

# =========================
# ÚLTIMA PASTA (ASCENDENTE)
# =========================

PASTA=$(ls "$BASE" | sort -V | tail -n 1)

# =========================
# ÚLTIMO .OPUS
# =========================

ARQUIVO=$(ls "$BASE/$PASTA"/*.opus 2>/dev/null | sort -V | tail -n 1)

if [ -z "$ARQUIVO" ]; then
    echo "❌ Nenhum voice encontrado"
    exit 1
fi

NOME=$(basename "$ARQUIVO")

echo "🎧 Voice:"
echo "$NOME"
echo ""

# =========================
# ÁUDIO MAIS RECENTE DOWNLOAD
# =========================

NOVO=$(find "$DOWNLOAD" -maxdepth 1 -type f \
\( -iname "*.opus" -o -iname "*.ogg" -o -iname "*.mp3" -o -iname "*.m4a" \) \
-printf '%T@ %p\n' 2>/dev/null | sort -n | tail -n 1 | cut -d' ' -f2-)

if [ -z "$NOVO" ]; then
    echo "❌ Nenhum áudio encontrado"
    exit 1
fi

echo "🎵 Novo áudio:"
echo "$(basename "$NOVO")"
echo ""

# =========================
# SUBSTITUI RÁPIDO
# =========================

cp -f "$NOVO" "$ARQUIVO"

echo "✅ Substituído com sucesso"

💡 Dica: Basta baixar qualquer áudio (OPUS, OGG, MP3, M4A) na pasta Download e executar o script!

🔧 DICA IMPORTANTE

Como descobrir seu Package Name

Se você não tem certeza se seu WhatsApp é Business ou não, use este comando no Termux:

$ pm list packages | grep whatsapp

O resultado será algo como package:com.whatsapp (normal) ou package:com.whatsapp.w4b (Business).

📖 COMO USAR

Passo a Passo Rápido

  • Baixe o áudio que você quer usar na pasta Download do celular
  • Grave um voice note qualquer no WhatsApp (será substituído)
  • Abra o Termux e cole o script (selecionando a versão correta acima)
  • Pressione Enter e veja a mágica acontecer! ✨

🔄 O script automaticamente:
→ Encontra o último voice note do WhatsApp
→ Encontra o áudio mais recente da pasta Download
→ Substitui um pelo outro instantaneamente!

🍎 INCOMPATÍVEL

Atenção Usuários de iPhone

O iOS possui um sistema fechado (Sandbox) que bloqueia totalmente o acesso a pastas de outros aplicativos. Por isso:

  • Não funciona com iOS normal
  • Não existe Termux para iPhone
  • Impossível acessar a pasta Voice Notes sem Jailbreak
